### 3. Long Description (Problem, Solution, Target Audience):
```
### Problem
In high-stress aerospace and deep-space missions, detecting structural anomalies, cryogenic leaks, and thermal fractures in rocket engines (such as turbopump vibrations and De Laval nozzle walls) requires sub-5ms real-time processing. Cloud-dependent vision pipelines suffer from extreme telemetry latency and bandwidth constraints.

### Solution
AMD-OmniSight is an ultra-fast, autonomous multimodal edge intelligence agent engineered for AMD Instinct (MI300X/MI250) and Radeon RX 7900 accelerators using AMD ROCm 6.2 and HIP kernels. By utilizing vectorized half-precision (FP16/BF16) tensor operations, OmniSight processes 230+ FPS with an unprecedented 4.19ms inference latency.

### Key Features
1. Native AMD ROCm Acceleration: Vectorized FP16 matrix operations.
2. Real-Time Anomaly Localization: Micro-fracture and thermal hotspot detection.
3. Edge Telemetry REST API: Fast asynchronous streaming via FastAPI and interactive HTML5 dashboard.
4. Uncompromising Efficiency: 9.4 FPS/Watt compute efficiency on AMD silicon.

### Target Audience
Space agencies (NASA, ESA), commercial aerospace manufacturers, satellite operators, and high-performance industrial robotics teams.
```
